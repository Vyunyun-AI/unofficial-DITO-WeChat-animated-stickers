# Contributing

Thank you for helping keep this sticker collection useful and easy to share.

## What to report

Open an issue for a broken or missing GIF, playback or transparency problems, spelling errors, incorrect pack counts, or a preview that does not match its files.

## Proposing changes

For small fixes, open a pull request with a short description of what changed. For a new sticker or pack, open an issue first so the pack name, preview, and file layout can be agreed before adding files.

This is a personal-interest, non-commercial project. Every contributed asset must be original work from the contributor or include clear permission for public redistribution under **CC BY-NC 4.0**. No contribution may be used commercially under this repository's license. Include any required attribution and source information. Do not submit material that relies on permissions this project does not have.
